# 房间完整呈现与柜架浏览

2026-11-14：修正影视柜被房间摆件遮挡，以及首屏房间出现后摆件才逐件出现的问题。保留现有 GitHub Pages 发布方式和完整画质。

## 首屏

- 以固定清单并行预取主房间、六个原生摆件 GLB 与 TARDIS 两张原始贴图。完整版本 URL 对应稳定的 Promise 和解码结果，避免重复请求及 Suspense 重试循环。
- 家具、书本、录像带、全部摆件和启用的自定义模型放在同一个 Suspense 边界内。等待记录数据、嵌入图片、外部贴图和 SMAA 查找图准备完成，再对完整场景异步编译材质程序。
- `compileAsync` 使用与后期处理相同的线性渲染目标。只有内容提交、编译成功，且经过后期处理的完整帧已绘制、WebGL 上下文有效时，才解除首屏遮罩。
- 遮罩使用不透明的昼夜背景，覆盖画布及其 HTML 内容。房间与摆件一次性淡入；减少动态效果的系统设置会取消淡入。加载期间锁定场景交互和区域下拉，避免在未准备完成时进入柜架或打开摆件。
- 根据固定清单的实际下载字节与解码状态计算进度，完成准备之前最高为 96%。后续发现贴图不会把进度从 100% 重置为 0%。下载字节更新只重渲染进度组件，不重建画布与后期处理通道。
- 夜间初次打开直接使用目标夜间灯光与黑色背景。之后手动切换昼夜仍保留原灯光过渡，不再从日间灯光开始首屏动画。

## 场景与界面

- 房间、影视柜、阅读书架各自拥有完整的对象树。进入柜架时房间家具、千年隼、佩剑、TARDIS 和用户模型全部卸出活动场景，因此不会遮挡、投影到柜架上或截获录像带点击。
- 返回房间复用已解码模型及图片。TARDIS 每个实例创建独立纹理对象、共享原始图片和不可变程序式像素，避免查看窗口关闭后释放房间仍在使用的纹理。
- 影视柜首次进入直接设置专用镜头和 38° 视场角；默认取景按窗口尺寸为标题、搜索和翻页留出空间。切换柜架保留平滑移动，系统减少动态效果时直接切换。
- 支持左右方向键翻影视柜，输入搜索文字时不拦截光标键；页码通过 `aria-live` 提示。沿用 Esc 返回、滚轮缩放、原有下拉导航。
- 搜索结果限制滚动高度，翻页按钮保留 44px 点击范围，窄屏提示可换行，搜索与翻页界面补充夜间颜色和键盘焦点状态。

## 异常与质量

下载停滞、解码超时、HTTP 错误、HTML 替代响应、截断 GLB、图片失败、画面长时间未绘制及 WebGL 上下文丢失均有恢复入口。首次任一必需物品失败时保留遮罩；重新打开会保留成功的原生模型缓存并重试失败资源。后台标签页暂停绘制超时判断，避免因浏览器暂停绘制而误报失败。

2026-11-14 的加载修正未修改模型文件、摆放、顶点、原始纹理像素、DPR、ULTRA SMAA、环境遮蔽或阴影分辨率。2026-11-15 的座椅重建另见 [棉质豆袋懒人沙发](BEANBAG.md)；当前七个 GLB 合计 27,649,396 字节、1,297,305 个三角面、275 组图元。TARDIS 原始程序式贴图逐字节哈希保持一致。
