# 保持画面效果的性能优化

保留完整模型、纹理分辨率、材质、灯光、阴影尺寸和环境遮蔽。没有新增低精度模型或移动时降画质。Blender 源文件保持原样。

总览清晰度修正：主场景 DPR 范围从 1–1.65 提高至 1.5–2，普通 1× 屏幕按每轴 1.5× 分辨率渲染，高分屏上限提高至 2×。在环境遮蔽和 AgX 色调映射之后新增 ULTRA SMAA，处理后期管线输出的边缘；监听查找图加载完成事件，让按需渲染的画面及时更新。透明背景的清屏色随昼夜主题切换，避免夜间轮廓混入白色。移动与静止保持相同清晰度，沿用缓存阴影和鼠标检测加速。

- 鼠标的硬件事件在每个显示帧合并处理，仍使用真实模型判断区域和物品。精细静态模型的 BVH 在 Worker 中生成，传递复制的数据，避免暂时移走正在显示的顶点缓冲区。标准检测作为失败时的后备。
- 五秒停留、边界宽限和区域切换冷却由独立计时器处理。停留本身不持续刷新整间房间。新移动尚未完成检测时，旧计时不会直接触发切换。
- 摆件查看窗口首次使用后保留画布和环境光资源，关闭时停止渲染；重新打开恢复默认观察角度。查看期间暂停背景房间，并在返回时刷新阴影。关闭窗口不新建 WebGL 上下文。
- 静态阴影继续缓存；书本、录像带、抽屉、窗帘的实际动画以及真实灯光变化会更新阴影。弹窗和导航锁定不再被误认为物体动画。
- GLB 使用无损 Meshopt 编码。原有房间与三件摆件的四个文件保持 17,108,876 字节与 821,579 个三角面。新增打火机从 2,117,112 字节压缩到 1,131,020 字节；现有五个 GLB 合计 18,239,896 字节、865,919 个三角面。编码前后校验全部顶点属性、有方向的三角面、原始纹理图片、材质和场景变换。校验摘要记录于 `model-compression.json`；第二版校验允许缓冲区引用重新编号，同时仍逐项验证实际几何数据与材质绑定。

2026-11-14 藏品扩充：新增安督利尔与接骨木魔杖，并重建黑色中空柳条后，七个 GLB 合计 23,500,908 字节、1,187,695 个三角面、277 组材质图元。安督利尔的 125 个原生零件导出为 14 组图元，魔杖 35 个零件导出为 6 组，柳条与包装共 5 组。展示背板和底座在查看窗口按场景副本切换显隐，不重新加载模型。主房间、公寓、千年隼和打火机保留原有文件哈希。以上是文件和几何检查结果，并非浏览器 GPU 耗时测量。

同日取景与纸盒修正：按当前模型尺寸计算居中和透视取景，保留查看窗口缓存；只有切换物品、窗口尺寸或查看方向时重新设定镜头，不新增逐帧包围盒遍历。柳条改为不规则开孔并插入无纸托的三棱柱盒内，21 个原生部件导出为 4 组图元。七个 GLB 当前合计 23,998,500 字节、1,227,333 个三角面、276 组图元；其他六个 GLB 保持原有哈希。新增细节继续使用无损编码，不减少既有画质。

运行 `node scripts/compress-models.mjs` 可在重新导出模型后进行压缩与一致性检查，随后运行 `npm run build` 更新发布版本。已经压缩且与报告一致的模型会保持原样。

验证包括 `npm run typecheck`、`npm run test:interaction`、`npm run test:performance`、`npm run test:clearance`、`npm run test:public` 和生产构建。性能测试还会通过真实 Worker 验证归一化、交错属性的数据传递，并比较所有房间视角中的原始与加速命中结果。

离线 CPU 检测及文件体积不等同于浏览器帧率。本轮没有浏览器 GPU 性能录制，不能据此承诺任何设备上的固定帧率。

首屏 100% 闪烁与加载恢复的后续处理见 [房间首屏加载与恢复](loading-reliability.md)：主房间先绘制，摆件逐件装入，版本化解码缓存、异步着色器准备、真实首帧判断及超时重试均保留完整画质。
