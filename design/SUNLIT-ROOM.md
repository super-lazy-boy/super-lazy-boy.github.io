# 日光书房 · 制作与验收

本轮修改基于已发布的 `56c31b7`。保留既有登录、记录、影视书库、留言与 TARDIS 模型；不迁移数据库，不把私密记录放入静态文件。

## 设计约束

- 房间外部及窗外保持纯白，有限的墙和地板呈现处于想象空间中的房间。
- 白色为家具主色。白漆、陶瓷、金属、塑料、织物通过反射与粗糙度区分。浅橡木、亚麻与鼠尾草绿提供有限点缀。
- 阳光、天空补光、环境反射及局部遮蔽分开控制。背景透明像素合成到白色网页，AgX 色调映射只影响房间物件。
- 静态家具与可操作物品使用同一世界尺寸。零件连接、承托接触和软包接缝属于设计接触；独立物件不得互穿。

## 原创模型与材质

`sunlit-room.blend` 保留可编辑部件、打光与离线渲染镜头，贴图打包在文件中。模型包含墙体、实木地板、踢脚线、窗框、锁柄、分格、帘杆、褶皱窗帘、办公桌、显示器、带打印字母的键帽、鼠标、独立主机、抽屉柜、五脚办公椅、音箱、台灯、杯具、纸笔、书架、收纳盒、媒体柜、空心播放机、投影幕、单人低坐座椅、脚凳、靠枕、地面坐垫、顺应座面曲面的毛毯、地毯、边几、手柄及底座、设备架、花架、编织收纳篮和留言角配件。

座椅以连续曲面制作，包含凹下的坐面、向后升高的软包边缘、滚边和接缝，落在低矮橡木平台上。植物分为宽叶观叶植物、小雏菊、茉莉与书架侧面垂落的绿萝；花瓣、花芯、叶面与叶脉分别建模。显示器居中，主机和抽屉分居桌下两端，纸笔、杯具与音箱保留独立空间。

原来两处装饰画已删除。《星空》在窗侧实墙上重新装裱，保持原图 1920∶1520 的比例，独立灯具照亮画面；点击可进入与 TARDIS 相同的旋转、缩放查看器。图像来源与说明见 `public/art/README.md`。

木纹与织物由 `make_textures.py` 以固定种子生成。无第三方生成服务、外部模型或在线 HDR 依赖。网页里的现有 TARDIS 仍使用其已审核模型；文字界面和动态记录物件继续由 React/Three.js 绘制。

Blender 世界坐标通过 `(x, -z, y)` 转换，导出的 glTF 使用网页 Y 向上坐标。布局数据位于 `public/models/sunlit-room/layout.json`。

重建命令（Blender 路径按本机安装调整）：

```powershell
python scripts/blender/make_textures.py
& 'D:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe' --background --factory-startup --python scripts/blender/build_sunlit_room.py
node scripts/optimize-room.mjs
npm run test:clearance
npm run build:github
```

增加 `-- --render` 可生成离线总览。`render_details.py` 用于原生源文件的近景渲染。渲染输出保存在忽略提交的 `work/qa/` 中，不能作为浏览器截图。

## 交互和碰撞

- 桌面端对可见家具进行实际射线检测，连续停留 2.4 秒进入区域，空白处停留 3 秒返回。150 毫秒的边缘宽限避免细小缝隙导致误切换；切换完成后冷却 1.5 秒，必须有新的鼠标移动才能重新开始判断。
- 移除空间文字标签与桌面端区域按钮。Alt+0～4 为键盘入口；触屏使用下拉选择区域，并保留受限拖动与双指缩放。输入、阅读、弹窗、动画和屏幕特写期间暂停区域判断。
- 灵感角先展示桌面、椅子、主机与周边物品，点击显示器后才拉近到屏幕。Esc 从屏幕回到书桌，再返回总览。
- 书籍先直线抽离书架，再抬升和旋转；地面书先抬离地面。归还使用严格反向路径。
- 录像带使用同一 `TapeCase` 模型，不在动画中替换外形或缩放。先抽出、抬升、转向、移至播放器前方、降低，再直线插入。播放器实际内腔留有尺寸余量。
- 同柜中切换影片时，先沿反向路径归还已装入的录像带，再取下一盘。跳过、切换区域和减少动态效果会清理动画状态。
- 三件地面书、地面纪念录像带、投影机和植物位于各自独立区域，避开柜前取放通道。
- 抽屉外壳与托盘尺寸分开，前脸位于外壳前侧，纸张底部高于托盘底板。
- 投影设备提高并置于座椅外侧。录像带完成插入后，镜头发光、投影光束和幕布方向的灯光同步开启；取出和装入期间关闭。光束在白天较淡、夜间更清楚。

## 白天与夜间

默认阳光模式，右上角切换昼夜并在本机记忆选择。夜间关闭太阳、降低天空和环境光，横向展开窗帘，启用桌灯、落地灯、画灯和书架灯带。桌灯与落地灯可分别开关。夜间放映时降低周围灯光，停止放映或切换回白天后恢复对应状态。外部和窗外始终保持白色，不添加城市、星空或黑色环境背景。

灯具出光面与实际灯光独立制作，并按各灯的类别分别控制。网页与 Blender 的灯位共用 `layout.json` 中的记录，通过测试防止灯光位置漂移。

`scene-clearance.test.mjs` 直接读取最终 GLB，正确解码量化顶点并应用节点世界变换；对实际三角网格建立 BVH。移动物品按包含封面、标签及外壳的定向包围体检查，每个动作阶段额外计算保守扫过体积。阶段边界独立分割，覆盖连续平移和旋转。录像带还检查相邻录像带、纪念摆件保留体积和抽屉外壳。抽屉检查各托盘部件及纸张，镜头检查全部区域与屏幕特写之间的直线路径。新增检查包括整幅画的可见网格、投影全幕光线路径、窗帘开合扫过区域、桌面物品包围体、独立键帽间距及灯位一致性。`layout.json` 同时保留合并前每个零件的实际世界包围盒。

验证范围包括当前固定布局及代码定义的尺寸。后续增添摆件、调整尺寸或更改路径时必须重新验证。用户上传的任意新模型不在现有固定资产的验收范围内，需单独核对位置。

## 验证限制

本轮已执行原生 Blender 离线渲染、类型检查、公开数据校验、碰撞与动画检查及生产构建。浏览器工具的自动权限审核拒绝了本地预览地址，因此没有完成本轮浏览器视觉和端到端交互验收。没有使用其他浏览器通道绕过该限制。部署是否更新通过发布文件与公开 HTTP 资源检查确认。
